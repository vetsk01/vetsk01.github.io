How to rebuild (no Kith)

  1. Refresh the case and D2/D3 as in my-work/week-6/fund-level/rerun-note-v2.md.
  2. python3 -I my-work/week-6/pipeline/build-d4-v1.py <repo-root> writes the JSON, the page and the pack. The page layout is my-work/week-6/pipeline/dashboard-template-v2.html; the pack rules are my-work/week-6/pipeline/query-pack-instructions-v2.md.
  3. python3 -I my-work/week-6/fund-level/dashboard/check_dashboard.py <repo-root> must print DASHBOARD PASS. python3 -I my-work/week-6/fund-level/tests/test_dashboard.py <repo-root> proves each check can fail.
  4. To use the pack: open the query-pack-v2 folder in Claude, as the project folder or as an attached folder, and ask questions.

The pack includes the decision log and dispositions, so rebuild it after any new decision, or the clean re-run check will report a difference.
