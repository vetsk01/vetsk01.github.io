How it is made

Figures and counts are tokens resolved from the data table, never typed: {{fig:<concept>}}, {{count:<concept>=<answer>}}, {{range:<concept>}}, {{row:<id>}}. The narrative is a reviewed file (my-work/week-6/pipeline/narrative-v2.json); descriptors are in my-work/week-6/pipeline/descriptors-v1.csv (a Fund I portfolio company, four; a Fund II portfolio company, six; minimum group size 3). Where a fund roll-up row exists the report uses it and does not add the company rows to it (QA Q22). By-fund rows are fund-only concepts named in the settings, so they are never summed with company rows. The Scope 3 and PCAF method is my-work/week-6/fund-level/library/methodology/scope3-pcaf-method-v1.md.
